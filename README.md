# ლუდის ხარშვის ასისტენტი

ერთფაილიანი ვებ-აპი (`index.html`): ხარშვის დღე ნაბიჯ-ნაბიჯ (BIAB, ~4 ლ), ტაიმერები ხმით,
კალკულატორი განზავებისთვის, დადუღების დღიური, ჩამოსხმა, Markdown/JSON ექსპორტი.

- გახსენი `index.html` ტელეფონზე ან ჩართე GitHub Pages (Settings → Pages → branch, root).
- მონაცემები ინახება ბრაუზერის `localStorage`-ში — გააკეთე JSON სარეზერვო ასლი (⚙).
- ტესტისთვის: ⚙ → Debug (ყველა ტაიმერი 10 წამი).
- რეცეპტები და ნაბიჯების ტექსტები: `DEFAULT_RECIPES` და `STEPS` ობიექტები `index.html`-ის დასაწყისში.
